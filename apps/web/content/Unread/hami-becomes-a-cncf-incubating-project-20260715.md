# HAMi becomes a CNCF incubating project | CNCF

## TL;DR

Hami joining CNCF incubation formalizes governance and community support for a project focused on in-network service discovery and observability, which may simplify platform integration and operations.

## Summary

The CNCF Technical Oversight Committee (TOC) has voted to accept HAMi as a CNCF incubating project.
